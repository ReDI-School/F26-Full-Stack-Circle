# Component reference screenshots

One screenshot per component from the ReDiCycle design system. Each ticket in the
[component backlog](https://github.com/ReDI-School/F26-Full-Stack-Circle/issues?q=is%3Aissue+label%3Astorybook)
embeds the matching image at the top, so you can see what you are building before you read a
word of the spec.

These are **reference images, not assets** — nothing in `frontend/` imports them. Build the
components with the design tokens in `frontend/src/assets/css/global.css`; never by eyedropping
a PNG.
